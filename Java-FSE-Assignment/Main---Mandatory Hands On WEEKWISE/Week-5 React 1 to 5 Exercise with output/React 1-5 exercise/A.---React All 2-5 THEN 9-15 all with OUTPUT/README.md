# React Labs Collection

This repository contains all the React hands-on labs completed during the Cognizant training program.

## 📁 Project Structure

### 1️⃣ StudentApp-ClassComponents
- **Topic**: React Class Components
- **Features**: Multiple class components in single file
- **Components**: Home, About, Contact
- **Learning**: Component class extension, render methods

### 2️⃣ ScoreCalculator-FunctionalComponent
- **Topic**: React Functional Components & External CSS
- **Features**: Props, external stylesheets, calculations
- **Components**: CalculateScore functional component
- **Learning**: Component props, CSS imports, percentage calculations

### 3️⃣ BlogApp-LifecycleMethods
- **Topic**: React Lifecycle Methods & API Integration
- **Features**: componentDidMount, componentDidCatch, axios
- **Components**: Posts class component with API calls
- **Learning**: Lifecycle hooks, state management, error boundaries

### 4️⃣ CohortApp-CSSModules
- **Topic**: CSS Modules & Conditional Styling
- **Features**: Scoped CSS, conditional colors
- **Components**: CohortDetails with CSS modules
- **Learning**: CSS modules import, conditional rendering

### 5️⃣ OfficeApp-JSXExpressions
- **Topic**: JSX Expressions & Dynamic Content
- **Features**: Object rendering, array mapping, conditional styles
- **Components**: Office space rental listings
- **Learning**: JSX syntax, dynamic content, inline styling

## 🚀 How to Run

Each project is a standalone React component. To run:

1. Create new React app: `npx create-react-app projectname`
2. Copy the respective files to `src/` folder
3. Install dependencies if needed: `npm install axios` (for BlogApp)
4. Run: `npm start`

## 📊 Technologies Used

- React 18+
- JavaScript ES6+
- CSS3 & CSS Modules
- Axios (for API calls)
- JSONPlaceholder API
