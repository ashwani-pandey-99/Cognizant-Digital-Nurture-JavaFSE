Objectives
- Explain how to resolve the conflict during merge.

In this hands-on lab, you will learn how to:
- Implement conflict resolution when multiple users are updating the trunk (or master)
  in such a way that it results into a conflict with the branch's modification.

Prerequisites
- Hands-on ID: "Git-T03-HOL_001"

Estimated time to complete this lab: 30 minutes.

========================================
CONFLICT RESOLUTION STEPS
========================================

1. Verify if master is in clean state.
   git status

2. Create a branch "GitWork". Add a file "hello.xml".
   git branch GitWork
   git checkout GitWork
   echo "<hello>Branch Content</hello>" > hello.xml

3. Update the content of "hello.xml" and observe the status.
   notepad++ hello.xml
   git status

4. Commit the changes to reflect in the branch.
   git add hello.xml
   git commit -m "Added hello.xml in GitWork branch"

5. Switch to master.
   git checkout master

6. Add a file "hello.xml" to the master and add some different content than previous.
   echo "<hello>Master Content</hello>" > hello.xml

7. Commit the changes to the master.
   git add hello.xml
   git commit -m "Added hello.xml in master with different content"

8. Observe the log by executing git log.
   git log --oneline --graph --decorate --all

9. Check the differences with Git diff tool.
   git diff master GitWork

10. For better visualization, use P4Merge tool to list out all the differences between master and branch.
    git difftool master GitWork

11. Merge the branch to the master.
    git merge GitWork

12. Observe the git mark up.
    (Git will show conflict markers in hello.xml like below)
    <<<<<<< HEAD
    <hello>Master Content</hello>
    =======
    <hello>Branch Content</hello>
    >>>>>>> GitWork

13. Use 3-way merge tool to resolve the conflict.
    git mergetool

14. Commit the changes to the master, once done with conflict.
    git add hello.xml
    git commit -m "Resolved merge conflict between master and GitWork"

15. Observe the git status and add backup file to the .gitignore file.
    git status
    echo "*.orig" >> .gitignore

16. Commit the changes to the .gitignore.
    git add .gitignore
    git commit -m "Added *.orig to .gitignore"

17. List out all the available branches.
    git branch -a

18. Delete the branch which was merged to master.
    git branch -d GitWork

19. Observe the log by executing git log.
    git log --oneline --graph --decorate
