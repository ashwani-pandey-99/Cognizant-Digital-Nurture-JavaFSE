# Core Java

Compile and run from this folder:

```powershell
javac -d out src\com\upskilling\employee\*.java
java -cp out com.upskilling.employee.Main
```

Covered areas:

- classes, objects, constructors, encapsulation
- inheritance-ready design through services and repository classes
- enum usage
- exception handling
- collections and generics
- streams, sorting, filtering, grouping, and summary statistics
- date API
- file writing with `java.nio.file`
