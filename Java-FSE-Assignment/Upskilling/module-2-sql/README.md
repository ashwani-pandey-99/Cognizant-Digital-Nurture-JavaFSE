# ANSI SQL Using MySQL

Run `employee_portal_mysql.sql` in MySQL Workbench or the MySQL command line.

Covered areas:

- database and table creation
- primary keys, foreign keys, unique constraints, and check constraints
- insert, update, select, filtering, ordering
- joins, grouping, aggregate functions, and subqueries
- date and string functions
- view, stored procedure, function, trigger, transaction
