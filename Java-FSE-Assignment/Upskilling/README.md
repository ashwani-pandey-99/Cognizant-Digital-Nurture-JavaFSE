# Upskilling Solution Pack

This folder contains working solutions for the six module areas:

- `module-1-web` covers HTML5, CSS3, Bootstrap 5, and JavaScript.
- `module-2-sql` covers ANSI SQL using MySQL.
- `module-3-core-java` covers Core Java.

The web module is built as a small employee operations dashboard so the HTML, CSS, Bootstrap, and JavaScript tasks work together instead of looking like disconnected practice snippets.
